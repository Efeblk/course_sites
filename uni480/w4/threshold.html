Threshold & Alert Lab

An early-warning model gives every patient a risk score. A threshold turns the score into an action: "review urgently" (slide 11). Lower thresholds catch more true cases but create more false alarms; higher thresholds reduce alerts but miss more patients. Find a threshold you could defend.

Scenarios:
Alert threshold (risk score)
Prevalence (who truly has it)
Model quality (separation)
Alerts the team can review

1,000 patients are scored. Scores and outcomes are simulated; they illustrate the trade-offs, not a real product.

Each threshold is one point: sensitivity vs false-positive rate. Moving the threshold moves along the curve; only a better model moves the curve itself. Prevalence does not change the curve — but it changes PPV and NPV.
