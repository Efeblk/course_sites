fork() Tree & Zombie Lab

fork() creates a child that is a copy of the parent and continues from the same point. It returns 0 in the child and the child's PID in the parent. Predict first, then run.

Part 2 — Make a zombie, make an orphan

A zombie has exited but its parent hasn't called wait() — its PCB stays in the process table holding the exit status. An orphan's parent died first — it is re-parented to init/systemd (PID 1), which reaps it.
