With dual-mode, the MMU only lets game.exe touch its own region. Anything else traps to the OS.

What happened

Remember: user → kernel only through a controlled entry point (system call, interrupt, trap). Privileged instructions in user mode trap to the OS. The timer guarantees the OS gets the CPU back — Linux default tick: 1 ms.
