Stages

  1. Device sends an interrupt signal on the bus
  2. CPU finishes the current instruction
  3. Save the PC of the interrupted instruction · switch to kernel mode
  4. Look up the handler in the interrupt vector
  5. Run the interrupt handler (service the device)
  6. Return from interrupt: restore PC · back to user mode
