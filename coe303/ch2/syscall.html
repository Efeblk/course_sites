Same idea, different OS

The API (POSIX read()) is the same on Linux, macOS, FreeBSD; the implementation differs (Linux vfs_read, macOS vn_read). Windows uses ReadFile(). Your program only cares about the API — "the interface is the contract; the implementation is the kernel's business."
