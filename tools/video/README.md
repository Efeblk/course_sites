# Course explainer videos

Narrated motion-graphics explainers for the course sites. Every scene is coded (React + SVG in
[Remotion](https://www.remotion.dev)) and rendered frame by frame, so labels, numbers and charts are exact.
Narration is a local neural voice ([Kokoro](https://github.com/thewh1teagle/kokoro-onnx), free, offline).

## Making a video

1. **Script** — `scripts/<name>.json`: a list of beats `{id, text}`. One beat = one narration clip.
   Optional per beat: `pause` (extra silence after, seconds), `hold` (minimum length, for a slow animation).
   Top level: `voice` (default `af_heart`), `speed`, `gap`.
2. **Voice** — `.tts/venv/bin/python tts.py scripts/<name>.json` writes `public/vo/<name>/*.wav` and
   `src/timelines/<name>.json` (start frame and length of every beat). Unchanged beats are cached.
3. **Scenes** — `src/<Name>.tsx`. Time every animation from the beats: `const { TL, B } = makeTL(timeline)`,
   then `p(f, B('beat').start, B('beat').start + 20)` gives an eased 0→1. Add `<Narration tl={TL} />` and
   `<Sfx at={…} name="ping" />` for sound. Register the composition in `src/Root.tsx`.
4. **Check frames** — `node stills.mjs 120,480,900 <CompositionId>` renders half-size stills to `stills/`.
5. **Render** — `./render.sh <CompositionId> out/<name>.mp4`.

Shared pieces: `src/lib.ts` (timing, easing, palette, normal distribution), `src/art.tsx` (bed, monitor,
staff figure with nurse/doctor looks, phone), `src/kit.tsx` (narration, sound effects). Icons come from
`lucide-react`.

Style rules that worked: tell a small story instead of listing facts; keep on-screen text to numbers and a few
labels (the voice carries the explanation); make the important number move; one idea per scene.

## SWE307 videos and Windows

The 16 SWE307 explainers (about 22 minutes) live in `src/swe/`: one file per video, shared drawing pieces in
`src/swe/kit.tsx` (labels, cards, people, UML shapes, a token that runs along a path). Their narration is written in
`scripts/swe307.py` (run it to regenerate `scripts/swe-*.json`; voice `af_heart` at speed 0.92, slower than UNI480).
`src/swe/index.tsx` is generated by `python src/swe/gen_index.py` from the files present.

On Windows (no `render.sh` / Mac Chrome path):

```sh
.tts/venv/Scripts/python.exe tts.py scripts/swe-fpa.json      # voice + timeline
node check.mjs sheet SweFpa swe-fpa                             # one half-size still at the end of every beat → chk/SweFpa/
python sheet.py SweFpa                                          # contact sheet chk/SweFpa-sheet.png, check it for overlaps
node render_all.mjs C:/Users/efeba/course_sites/materials/SWE307/video [SweFpa ...]   # 1080p mp4 + jpg poster
```

The rendered files go to `materials/SWE307/video/` (committed with the course); `swe307/videos.html` plays them.

## COE303 episodes (`src/os/`)

Eight episodes of about two and a half minutes (about 20 minutes in total) for chapters 1–6, rendered to
`materials/COE303/video/` and played by `coe303/videos.html`. They raise the motion bar over the SWE307 set:

- **One cast for the whole series.** Processes are small characters (`Proc` in `src/os/kit.tsx`: blink, breathe,
  look, squash on landing, moods such as focus, worried, sleep, dizzy); the CPU is a chip (`Chip`) that ripples when busy.
- **Story first.** Each episode opens on a concrete puzzle ("you press a key: how does the CPU know?"), lets the
  wrong way fail on screen (a shake and a cross), then shows the right way, and ends with the `Exam` checklist card.
- **Motion helpers:** `hop` / `track` (arc moves with squash), `Cam` (pan and zoom inside a scene), `Fly` (a value
  flying between cells), `Draw` (self-drawing strokes), `Code` (typed code with a moving highlight), `Episode` (title
  card, crossfades, corner tag).
- **Scheduling simulator.** `plan(procs, slices, a0, a1, H, layout, enter, anchors)` turns a schedule (from
  `coe303/sched.js`) into motion: characters hop between the ready queue, the CPU and the done shelf, the running one's
  "left" tag drains, the waiting ones' "wait" tags tick, and `Gantt` grows in step. `anchors` pin a simulated time to a
  frame (two anchors with the same time make a pause), so the schedule waits for the voice.

```sh
python scripts/coe303.py                                   # narration -> scripts/os-*.json (lead 2.6 s leaves room for the title card)
.tts/venv/Scripts/python.exe tts.py scripts/os-fcfs.json   # voice + timeline
python src/os/gen_index.py                                 # register the episodes found in src/os/
node check.mjs sheet OsFcfs os-fcfs && python sheet.py OsFcfs
node render_all.mjs ../../materials/COE303/video OsFcfs     # writes fcfs.mp4 + fcfs.jpg
```
