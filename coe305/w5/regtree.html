Regression Tree & Pruning

A regression leaf predicts gₘ = the average r of the instances that reach it. Node error Eₘ = (1/Nₘ) Σₜ (rᵗ − gₘ)². Split where the error after splitting is smallest, and stop (prepruning) when Eₘ < θᵣ.

Model selection in trees: error vs θᵣ

Small θᵣ → big tree → training error falls toward 0 but test error rises (variance). Large θᵣ → tiny tree → both errors high (bias). Pick θᵣ on validation data. Postpruning instead grows the full tree and cuts back subtrees that do worse on a separate pruning set (scikit-learn: ccp_alpha, Project Task 5).
