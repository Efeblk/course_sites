Subset Selection

Feature selection keeps k of the d original features. Trying all 2ᵈ subsets is too expensive, so we search greedily using the validation error E of a model trained on each candidate subset (here: least-squares regression predicting the exam score).

The data: 400 students, d = 6 features

200 students train each model, the other 200 are the validation set that gives E. Two features are irrelevant on purpose and one is redundant — can the search tell?

The slide's rule is ε = 0. Run both searches, then try ε = 0.5: an irrelevant feature can lower the validation error a tiny bit just by fitting noise.

Forward search

F = ∅. Each step add xⱼ = argminᵢ E(F ∪ xᵢ), but only if E(F ∪ xⱼ) < E(F). Click a row to add it yourself, or let the algorithm choose.

Backward search

Start with all features. Each step remove the feature whose removal gives the lowest E, if E does not get worse.

Exhaustive check: all 2⁶ = 64 subsets
