k-Means Lab

Find k reference vectors mᵢ that best represent the data. Each point uses its nearest reference; the reconstruction error E = Σₜ Σᵢ bᵢᵗ ‖xᵗ − mᵢ‖² measures how badly the mᵢ stand in for the points.

Data:
Initialize mᵢ, i = 1…k, e.g. to k random xᵗ
Repeat
  bᵢᵗ ← 1 if ‖xᵗ − mᵢ‖ = minⱼ ‖xᵗ − mⱼ‖, else 0
  mᵢ ← Σₜ bᵢᵗxᵗ / Σₜ bᵢᵗ
Until mᵢ converge

Choosing k: elbow

Best of 5 k-means++ runs for every k. Look for where the curve stops dropping sharply.

Choosing k: silhouette

s = (b − a) / max(a, b) averaged over points: a = mean distance to its own cluster, b = to the nearest other cluster. Higher is better; Project Task 4 asks for both plots.
