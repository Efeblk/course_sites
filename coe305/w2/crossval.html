K-Fold Cross-Validation

To estimate generalization error we need data the model has not seen. With plenty of data: training 50%, validation 25%, test 25%. With little data we resample: split into K folds, train on K − 1, validate on the one left out, rotate, and average.

Project Task 1: compare K

Same data, same model, K = 3, 5, 10, each repeated with 10 different shuffles.

Larger K → each model trains on more data (K − 1 of K folds), so the estimate is less pessimistic, but you train K models and each validation fold is smaller (its score is noisier).
