Embedding Space

Dense embeddings put words with similar meaning close together, and directions can carry meaning: vec("king") − vec("man") + vec("woman") ≈ vec("queen"). Real models use 50–300 dimensions; this toy map uses 2 so you can see it.

Static vs contextual: which "bank"?

Word2Vec/GloVe store one vector for "bank". A contextual model (ELMo, BERT, GPT) builds the vector from the sentence. Toy rule here: contextual bank = ½·static bank + ½·average of the other known words in the sentence.
