Bulldozer or Nutcracker?

"Don't use a bulldozer to crack a chestnut." The lecture's question: when would I NOT use an LLM? Plug in numbers and decide for yourself.

1 · Unit cost: spam filtering

The slide's numbers: GPT-4 API $0.03 per 1K tokens → $30,000/month vs Naive Bayes < $10/month; 98.5% vs 99.2% accuracy. $30,000/month at 1M emails/day works out to about 33 tokens per email. Real emails are usually longer, so try 300 tokens and watch the gap grow.

2 · Latency: response time matters

Real-time applications — autocomplete, live translation, chatbots: users drop off after about 100 ms (the orange line).

3 · Which tool? (other factors)

For each case pick a tool, then see the deciding factor: cost, latency, interpretability, privacy, customization (small labeled data), hallucinations.
