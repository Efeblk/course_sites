3. Açık uçlu: kalıp ve 4 hazır cevap

Yarım sayfa, 4 parça: (1) Verdict, 1 cümle · (2) Mechanism: ne girer, ne çıkar, formül ne demek · (3) Why not the alternative · (4) Limit + nasıl test edersin. Kalın kelimeler puanın geldiği yer; onları bil, cümleyi kendin kur.
W1: "Would you use an LLM for spam filtering?"

Verdict: No. For a simple, high-volume task I would use a classical model such as Naive Bayes.

Why: the accuracy gain is tiny (about 0.7 points) but the LLM costs about 3000× more (~$30,000 vs under $10 a month for 1M emails a day) and is much slower (100–1000 ms vs under 10 ms). A small model is also interpretable, keeps data private (no external API) and does not hallucinate.

When an LLM is right: open-ended generation or complex question answering.

W3: "Why did we move from bag of words to Transformers?"

BoW / TF-IDF turn text into numbers but lose word order ("dog bites man" = "man bites dog"); a different classifier cannot bring it back. Embeddings give similar words similar vectors, but they are static and averaging loses order.

A CNN learns local patterns ("not very good") but misses distant relations. An RNN reads in order with a hidden state, but the gradient vanishes over long distances (0.520 ≈ 10−6). An LSTM adds gates and a cell state to keep information longer, but is still sequential.

A Transformer lets every word attend directly to every other word, in parallel: softmax(QKT/√dk)V. BERT is a pretrained bidirectional encoder fine-tuned with a small head. Limit: cost grows with T² and long inputs are truncated.

W6: "HMM or CRF for NER?"

Verdict: a linear-chain CRF, because NER needs rich clues about each word and consistent neighbouring labels.

Mechanism: a CRF models P(Y|X) = exp(S)/Z directly. S adds unary scores, which can use overlapping features (capitals, suffixes, name lists, encoder outputs), and transition scores that reward pairs like B-PER → I-PER. Viterbi (max) finds the best sequence; Z (sum) is only needed for probabilities and the loss.

Why not an HMM: its emission P(word | tag) sees only the current word, so overlapping clues are hard to add.

Limit: finite scores do not guarantee legal BIO, so I set illegal transitions to −∞ and evaluate with exact-match span F1 on a held-out test set.

W6: "Why span F1 instead of token accuracy for NER?"

Verdict: token accuracy is misleading; entities should be scored as exact-match spans.

Mechanism: most tokens are O. With 90 O tokens out of 100, predicting O everywhere gives 90% accuracy but 0% entity recall. A span counts only if boundaries and type both match: 3 gold, 4 predicted, 2 exact → P 0.5, R 2/3, F1 = 4/7 ≈ 0.57.

Limit: "Acme" for "Acme Labs" counts as wrong. Micro favours frequent types, macro weights each type equally, so state which one you use.

İki kısa cevap daha: NER vs POS, NB vs LR vs SVM

NER vs POS: NER is harder because it solves two problems at once: segmentation (where a name starts and ends, "New York") and type ambiguity (the same name, "Washington", can be PER, ORG, LOC or GPE). It is labelled per token with BIO but evaluated as spans. IO needs n + 1 tags, BIO 2n + 1, BIOES 4n + 1; IO cannot separate two adjacent entities of the same type.

NB vs LR vs SVM: Naive Bayes is generative: it picks the class with the largest P(c)·∏P(word|c); fast, good baseline, but assumes words are independent given the class and needs smoothing. Logistic regression is discriminative: p = σ(w·x + b), a probability with a linear boundary. SVM picks the maximum-margin boundary; the sign gives the class but the score is not a probability. None of them recovers word order lost in the features.

4. Şıkta görürsen: hepsi yanlış

  • Text classification gives one label per token. Bu token classification (W4, W6).
  • NB is discriminative, LR is generative. Tam tersi. · NB is naive because it needs no training data. Naive = bağımsızlık varsayımı.
  • An SVM score of 2 means 200% confidence. Skor olasılık değil.
  • Counting "!" is a lexical feature. Statistical.
  • df(good) = 3 because good occurs three times. df doküman sayar.
  • The test set has no labels, so fit_transform on it is fine. Leakage.
  • Without smoothing, an unseen word has no effect. Çarpımı 0 yapar.
  • If all features are zero, nothing is learned. Bias öğrenir (p − y).
  • Gradient clipping fixes vanishing gradients. Sadece exploding.
  • More attention heads recover a truncated ending. Metin modele hiç ulaşmadı.
  • The [MASK] token removes a position from attention. Kelimeyi gizler, konumu değil.
  • F1 is the arithmetic mean of P and R. Harmonik. · TN is part of F1. · Macro-F1 favours the larger class.
  • About 15% of tokens are ambiguous. %15 type, ~%60 token. · POS is solved at 97%.
  • Prepositions are an open class. ADP kapalı sınıf.
  • 90% accuracy means 90% of the entities were found. Payda farklı.
  • Acme instead of Acme Labs is correct because the type is right. Sınır yanlış.
  • A bigger Transformer fixes nested entities. Sorun BIO temsilinde.
  • 0.1344 is the posterior of VN. Joint; posterior ≈ 0.549. · b(N, can) is P(N | can). P(can | N).
  • Viterbi keeps only the single best state after each word. Her etiket için en iyi kısmi yolu tutar.
  • HMMs can only be used for POS. NER etiketleri de olabilir.
  • A transition score of 2 is invalid. Skor, olasılık değil. · Z is needed to choose the best path.
  • Training a CRF guarantees legal BIO. Sonlu skor caydırır; −∞ gerekir.
  • Shape (2,5,3) means two labels. 2 cümle, 5 konum, 3 etiket.
  • A softmax head scores neighbouring label pairs. Sadece HMM ve CRF.
