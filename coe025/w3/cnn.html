CNN Text Filter

A text CNN slides a learned filter over windows of word vectors. Each window gives one response (multiply, sum, add bias, ReLU). Pooling then squeezes all positions into one number per filter.

1 · One filter, sliding

Toy word vectors (2 features each)

Width-2 filter (one row per window position)

The same filter weights are reused at every position (weight sharing). Its response is a feature, not a probability: 2 doesn't mean "200% positive". Pooling discards where the strongest window was.
